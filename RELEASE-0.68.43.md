# MineLatino Launcher 0.68.43

- Las miniaturas 3D de cosméticos cargan manifiestos y texturas con manejo visible de errores, color sRGB y materiales de doble cara.
- El perfil recomendado se crea de forma segura una sola vez y soporta Fabric, Quilt, Forge y NeoForge.
- Los mods automáticos se descargan y verifican antes de retirar la versión anterior; también se conserva el nombre real del archivo en sistemas sensibles a mayúsculas.
- El actualizador ASAR crea una copia de respaldo, revierte una instalación fallida y elimina archivos pendientes después de una actualización correcta.
- Electron Builder, Vitest y sus dependencias transitivas se actualizaron a versiones sin vulnerabilidades conocidas.

Validación: TypeScript/Vue, pruebas MineLatino, build del renderer, empaquetado Windows y auditoría completa de dependencias.
