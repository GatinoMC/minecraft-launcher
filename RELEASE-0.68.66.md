GatinoLauncher 0.68.66 para Windows x64.

- Añade perfiles optimizados predeterminados para Minecraft 1.21.4, 1.21.11 y 26.2.
- Incluye los mods y la configuración inicial de GatinoLauncher en cada perfil.
- Verifica los mods descargados mediante hashes antes de instalarlos y elimina versiones administradas obsoletas de forma segura.
- Reduce la espera al pulsar **Empezar**: el perfil seleccionado ya no espera la sincronización de los demás perfiles.
- Muestra seis anuncios en el carrusel y renderiza correctamente los emojis personalizados de Discord.
- Mantiene el comprobador de actualizaciones conectado exclusivamente a las publicaciones de GatinoMC.

Descarga el archivo `.exe` para instalar, o el `.zip` para usar la versión portátil.
También se publican checksums SHA-256 y el ASAR firmado para las actualizaciones automáticas.

**Aviso:** el instalador todavía no tiene firma Authenticode. Verifica el SHA-256
publicado antes de ejecutarlo. La firma Authenticode se habilitará cuando termine
la configuración externa de SignPath.
