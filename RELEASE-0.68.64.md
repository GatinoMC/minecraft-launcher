MineLatino Launcher 0.68.64 para Windows x64.

- Corrige «Reiniciar y actualizar» cuando Windows bloquea el archivo del launcher en uso.
- Muestra los errores de actualización en pantalla y evita iniciar dos instalaciones simultáneas.
- Evita ofrecer versiones anteriores como si fueran actualizaciones nuevas.
- Permite reclamar cosméticos gratuitos y muestra el stock disponible y los productos agotados.

Descarga el archivo `.exe` para instalar, o el `.zip` para extraer el launcher.
Se incluyen los paquetes ASAR y las sumas SHA-256 para verificar las descargas.

Esta release se distribuye desde GatinoMC/minecraft-launcher. Las instalaciones
anteriores pueden seguir consultando el canal de actualizaciones configurado;
para instalar esta versión, utiliza los archivos de esta página.
