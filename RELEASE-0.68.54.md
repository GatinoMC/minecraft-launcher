# MineLatino Launcher 0.68.54

- El probador de cosméticos ahora permite recorrer todos los productos con flechas anterior y siguiente.
- Se añadió un contador para indicar qué cosmético se está previsualizando.
- El cosmético seleccionado se conserva al buscar, filtrar o actualizar el catálogo.
- Al abrir un producto desde el catálogo, el probador 3D se sincroniza con ese cosmético.
