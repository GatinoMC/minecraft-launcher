GatinoLauncher 0.68.68 para Windows x64.

- Añade Simple Voice Chat 2.6.22 por defecto a los perfiles GatinoLauncher 1.21.4, 1.21.11 y 26.2.
- Sincroniza los perfiles existentes con el catálogo actualizado al abrir el launcher.
- Conserva FOV Quake Pro, escala de interfaz x2 y el contador de FPS de Sodium Extra desactivado.

Descarga el archivo `.exe` para instalar, o el `.zip` para usar la versión portátil.
También se publican checksums SHA-256 y el ASAR firmado para las actualizaciones automáticas.

**Aviso:** el instalador todavía no tiene firma Authenticode. Verifica el SHA-256
publicado antes de ejecutarlo. La firma Authenticode se habilitará cuando termine
la configuración externa de SignPath.
