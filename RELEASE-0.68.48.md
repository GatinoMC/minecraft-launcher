# MineLatino Launcher 0.68.48

- Añade la categoría **Skins** al catálogo de cosméticos.
- Reconoce los paquetes ZIP de personajes animados publicados por MineLatino.
- Evita interpretar una Skin animada como un cosmético Java convencional.
- Actualiza automáticamente MineLatino Cosmetics a `0.1.0-alpha.21` después de descargar y verificar el nuevo JAR.
- Mantiene el mod anterior si la descarga o su comprobación de integridad fallan.
